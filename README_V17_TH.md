ระบบมือแบบใหม่
1. เปิดกล้อง / รอ Hand AI โหลด
2. กด “ถัดไป · สแกนมือ”
3. ยกฝ่ามือให้เห็นครบ 5 นิ้ว ค้างประมาณ 1 วินาที
4. ระบบแสดงเปอร์เซ็นต์สแกน 0–100%
5. เมื่อขึ้น “มือพร้อมใช้งาน” จึงเปิด Swipe / Pinch / Fist / Two-Hand Power
6. ปลายนิ้วชี้ใช้เป็น Pointer ได้
7. ชี้ค้างบนปุ่ม “เริ่มภารกิจ” หรือ “ไปต่อ” ประมาณ 0.7 วินาทีเพื่อกดโดยไม่ใช้เมาส์
8. ถ้ามือหลุดจากกล้องนาน ระบบจะล็อก Gesture และให้สแกนมือใหม่ก่อนใช้งานต่อ
