แก้ระบบมือโหมด 2 คนใหม่แบบ Strict Lane
- P1 ใช้เฉพาะมือที่อยู่ครึ่งซ้ายของจอ
- P2 ใช้เฉพาะมือที่อยู่ครึ่งขวาของจอ
- Track ของ P1/P2 จะไม่สลับกันเมื่อมือเข้าใกล้กลางจอ
- ปัดซ้าย/ขวาถูกตรวจแยกคนละ state ไม่แชร์กัน
- ปัดประมาณครึ่งฝ่ามือก็ทำงาน โดยไม่ใช้ velocity gate
- ถ้ามือออกนอกฝั่ง ระบบจะหยุดรับ gesture และบอกให้กลับเข้าฝั่ง
