# Abstract Hero AR V4 — Hand AI Visible

เวอร์ชันนี้แก้จาก V3 โดย **ไม่เอาระบบมือออก** และทำให้ Hand AI เห็นสถานะชัดตลอดเวลา

## สิ่งที่เพิ่ม
- แถบ HAND AI ACTIVE ด้านล่าง
- แสดง 6 ท่าหลักตลอดเวลา: ปัดซ้าย / ปัดขวา / จีบ / กำมือ / ยกฝ่ามือ / สองมือ
- ตัวชี้มือใหญ่ขึ้นและแสดงไอคอนฝ่ามือเมื่อระบบจับมือได้
- โหมด SOLO มีคำแนะนำให้แบมือค้าง ~0.6 วินาทีเพื่อเริ่มด้วยมือ
- VS 2 Players, Player Lock และ Safe Zone จาก V3 ยังอยู่ครบ
- MediaPipe Hand Landmarker / Gesture state machine เดิมยังอยู่ครบ
