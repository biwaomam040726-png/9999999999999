Abstract Hero AR V27

แก้ปัญหา P1 ปัดแต่คะแนนไป P2 แบบตัดระบบ owner เก่าทิ้งในโหมด VS

หลักการใหม่
- P1/P2 ถูกตัดสินจากกรอบ DOM ที่มือถูกวาดอยู่จริงบนหน้าจอ
- มือที่วาดอยู่ในกรอบ P1 เรียกคะแนน P1 เท่านั้น
- มือที่วาดอยู่ในกรอบ P2 เรียกคะแนน P2 เท่านั้น
- โหมด VS ไม่ใช้ track.owner / handedness / calibration owner เก่าในการให้คะแนนอีก
- Swipe ใช้ anchor displacement แบบง่าย: ปัดประมาณ 1/3–1/2 ฝ่ามือ
- ระบบ track เดิมถูกจำกัดให้ทำงานเฉพาะ SOLO
