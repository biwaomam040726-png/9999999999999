Abstract Hero AR V9

สิ่งที่ปรับรอบนี้
1) ปัดซ้าย/ขวาติดแทบจะทันที
- ลด threshold ของการปัด
- ลด cooldown / re-arm
- ขยาย gesture window
- เพิ่มโซนปลอดภัยในโหมด 2 คน เพื่อลดการแย่งกัน

2) คำตอบลอยแบบ 3D มากขึ้น
- ปุ่มคำตอบลอยแบบ orbit ชัดขึ้น
- มีมิติหมุนเล็กน้อยด้วย rotateY / translateZ
- ซ่อนข้อความย่อยที่รกตาออก

3) โหมด 2 คนเสถียรกว่าเดิม
- home zone ชัดขึ้น
- safe zone กลางจอกว้างขึ้น
- action zone ของแต่ละคนแยกชัดขึ้น

4) คำถามกลับมาเด่นขึ้น
- เพิ่มความชัดของข้อความคำถามบนการ์ด
- ปรับสี/ขนาดให้อ่านง่ายกว่าเดิม

5) เลือกได้ว่าจะใช้แบบไหน
- Gesture / กล้อง
- Touch / กดคำตอบบนหน้าจอ

วิธีใช้เร็วสุดบน GitHub Pages
- อัปไฟล์ index.html ทับของเดิม
- Commit / Push
- รอ deploy แล้วกด Ctrl+F5
