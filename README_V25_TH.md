Abstract Hero AR V25

แก้ระบบมือโหมด 2 คนใหม่แบบ Zone-Locked

- P1 = มือที่อยู่ครึ่งซ้ายของภาพ ณ เฟรมนั้นเท่านั้น
- P2 = มือที่อยู่ครึ่งขวาของภาพ ณ เฟรมนั้นเท่านั้น
- ไม่ใช้ owner จาก track เก่ามาคิดคะแนนอีก จึงตัดปัญหา P1 ปัดแต่คะแนนไป P2
- Skeleton สีฟ้าถูกวาดจากมือฝั่งซ้าย และสีม่วงจากมือฝั่งขวาโดยตรง
- Swipe มี state แยก P1/P2 และใช้ระยะประมาณครึ่งฝ่ามือ
- ข้ามกลางจอไม่ได้: เข้า Safe Zone แล้ว reset gesture ไม่ย้ายคะแนนไปอีกคน
- Two-hand Power นับเฉพาะจำนวนมือที่อยู่ในครึ่งจอของผู้เล่นคนนั้น

ทดสอบ index.html โดยแยก module script และรัน node --check ผ่านแล้ว
