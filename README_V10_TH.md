Abstract Hero AR V10

รอบนี้แก้แบบเน้น "โล่ง" จริง

สิ่งที่แก้หลัก
1. เปิด Clean HUD เป็นค่าเริ่มต้นทันที
- ซ่อน panel ซ้าย/ขวา
- ซ่อนแถบคำสั่งด้านล่าง
- ซ่อนข้อความกลางหัวจอที่รกตา

2. คำตอบลอยทั่วจอมากขึ้น
- ปุ่มซ้าย/ขวาไม่เกาะอยู่แค่ข้างการ์ด
- เปลี่ยนเป็นลอย orbit รอบพื้นที่เล่น
- วิ่งกว้างขึ้นทั้งจอ โดยเฉพาะในโหมด Clean HUD

3. โฟกัสเหลือแค่ 3 อย่าง
- การ์ดคำถาม
- คำตอบลอย
- timer/ปุ่มหลักด้านบน

4. ยังเลือกได้เหมือนเดิม
- ใช้มือ / กล้อง
- หรือเปิด Touch Mode เพื่อกดบนจอ
